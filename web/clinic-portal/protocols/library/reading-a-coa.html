Do not administer if
  • •The lot number on the COA does not match the vial
  • •Any release test is missing, pending, or marked out of specification
  • •The expiry has passed or the date is ambiguous
  • •The COA is unsigned or the document is illegible
  • •The lot passed through an undocumented temperature excursion
  • •The cell or particle count is inconsistent with the dose you planned
  • •The donor eligibility statement is absent
Filing
  • •Keep the original COA with the chain-of-custody log for that lot
  • •Place a copy or the lot number in each recipient's chart
  • •Retain the vial label or a photograph of it where policy requires
  • •Request a replacement COA from CelluNOVA before use if one is missing
